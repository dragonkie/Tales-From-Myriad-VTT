# Tales from Myriad System

![Foundry v13](https://img.shields.io/badge/foundry-v13-green)

A TTRPG system created by and Copyrighted by Carson Daniels, Tales from Myriad is a whimsical game of high stakes,
risky encounters, and sometimes sheet luck. But most of all, it has the best hats you've ever seen!
